# Investigaciones

Aquí caen los informes de Gemini (Deep Research) o Perplexity cuando creas una skill por la vía de
investigación.

## Cómo se organiza

```
investigacion/
└── <nombre-de-la-skill>/
    ├── prompt.md            ← lo que se pegó en Gemini o Perplexity
    └── investigacion.md     ← lo que devolvió, tal cual
```

Claude escribe el `prompt.md` y te lo muestra listo para copiar. Tú lo pegas en Gemini con **Deep
Research** activado, esperas, y guardas el resultado como `investigacion.md`. Después vuelves y
escribes `listo`.

Si no quieres pelear con archivos, pega el informe directo en el chat: Claude lo guarda por ti.

## Por qué se conserva el informe crudo

De un informe de treinta páginas sale una skill de dos. El resto no es basura: es de dónde salió
cada regla. Cuando dentro de un año una cifra ya no cuadre, este archivo es el que dice de dónde
venía y de qué fecha era.

No lo borres, y no lo pegues entero dentro de la skill. Cada uno en su sitio.
