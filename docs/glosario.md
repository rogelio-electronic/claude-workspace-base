# Glosario

Las palabras que vas a ver, en cristiano.

| Palabra | Qué es de verdad |
|---|---|
| **Workspace** | Una carpeta. Claude solo ve la carpeta desde la que lo abriste: eso es todo el misterio |
| **`CLAUDE.md`** | Un archivo de texto con las instrucciones permanentes de esa carpeta. Se lee entero en cada sesión |
| **Skill / habilidad** | Una carpeta con instrucciones para una tarea concreta. Se activa sola cuando pides algo que encaja con su descripción |
| **Descripción de una skill** | La línea que dice qué hace y cuándo usarla. Es lo único que Claude lee siempre, y lo que decide si la skill aparece |
| **Contexto** | Todo lo que Claude está leyendo en este momento. Tiene límite, y llenarlo de cosas que no aportan es el error más caro |
| **Token** | El pedacito en que se mide el texto. Unas tres cuartas partes de una palabra. Sirve para comparar qué te cuesta cada cosa |
| **Sesión** | Desde que abres Claude hasta que lo cierras. Al cerrar se olvida de la conversación; lo que está escrito en archivos, no |
| **Prompt** | Lo que le escribes. Nada más |
| **Slash command** | Escribir `/algo` para llamar a una función directamente, sin explicar. Aquí: `/empezar`, `/ayuda` |
| **Hook** | Una orden que se ejecuta sola cuando pasa algo (antes de guardar, después de un comando). Este workspace no trae ninguno |
| **MCP** | Un conector a otra herramienta: tu correo, una base de datos, Notion. Se agrega cuando hace falta |
| **Plugin** | Un paquete de skills hecho por otra persona. Útil, y hay que revisarlo antes de confiar |
| **Ablación** | Apagar todo y devolver solo lo que demuestre que hace falta. El método con el que se mantiene esto flaco |
| **Hobbling** | Frenar al modelo con instrucciones que ya no hacen falta. El problema más común hoy, y el más invisible |
| **Guardarraíl** | Un límite ("no toques esto") en vez de un paso ("haz esto y luego esto"). Los límites encauzan; los pasos frenan |
| **Criterio de término** | Cómo sabe que terminó. Sin esto entrega algo que parece listo y se va |
| **Deep Research** | El modo de investigación profunda de Gemini o Perplexity: tarda minutos y devuelve un informe con fuentes |
| **Bitácora** | El archivo donde queda anotado qué se decidió y por qué. Para que en seis meses se entienda |
